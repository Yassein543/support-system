تحدد هذه السياسة الاستخدامات المسموحة لموقع YS-Bot وبوته وواجهات لوحة التحكم. وهي مكملة لشروط الخدمة وسياسات Discord.

الاستخدامات الممنوعة

  • استخدام البوت لإرسال رسائل مزعجة أو منشنات جماعية متكررة أو مضايقة الأعضاء.
  • استخدام ميزات الإشراف أو التذاكر أو النسخ أو روابط التخصيص لإيذاء المستخدمين أو خداعهم أو الوصول غير المصرح به.
  • محاولة تعطيل الموقع أو البوت، تجاوز حدود الاستخدام، استغلال الثغرات، أو فحص أنظمة لا تملك إذنًا باختبارها.
  • رفع محتوى غير قانوني أو ينتهك حقوق الآخرين أو قواعد Discord.
  • استخدام الأوامر أو مفاتيح API أو روابط مؤقتة لحساب أو سيرفر لا تملك صلاحية إدارته.

إدارة السيرفر وصلاحيات البوت

امنح البوت أقل الصلاحيات اللازمة، وتحقق من إعدادات الحماية قبل تطبيقها. أنت مسؤول عن أفعال المشرفين وعن صحة القنوات والأدوار التي تربطها بالميزات.

الإبلاغ عن مشكلة

إذا وجدت إساءة أو ثغرة، لا تستغلها ولا تنشر بيانات الآخرين. أرسل وصفًا مختصرًا إلى فريق الدعم مع خطوات إعادة المشكلة، دون تضمين كلمات مرور أو رموز سرية.
